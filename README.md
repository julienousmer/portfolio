# Portfolio — Julien Devienne-Ousmer

Personal portfolio of Julien Devienne-Ousmer, full-stack web developer (PHP/Symfony, Angular).

Live: https://julien-devienne-ousmer-portofolio.vercel.app/

## Stack

- Angular 18, TypeScript
- Tailwind CSS
- Deployed on Vercel, with Vercel Web Analytics

## Content

All texts (French and English) live in `src/app/data/portfolio.data.ts`.
The CV and the photo are in `public/`.

## Development

```bash
npm install
npm start        # http://localhost:4200
npm run build    # output in dist/untitled/browser
npm test
```
